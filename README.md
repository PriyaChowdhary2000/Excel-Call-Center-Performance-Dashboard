# Call Center Performance Dashboard (Excel)

This Excel dashboard provides a comprehensive overview of call center performance, enabling data-driven decision-making for call center management.

## Key Features

*   **Overall Performance:** Displays total call count, total revenue, average call duration, and average customer satisfaction rating.
*   **Monthly Trends:**  Visualizes call volume by month.
*   **Daily Trends:**  Shows call volume by day of the week.
*   **Representative Performance:**  Ranks and compares individual representative performance based on call volume and revenue generated.
*   **Geographical Analysis:**  Breaks down revenue by city (Cincinnati, Cleveland, Columbus).
*   **Demographic Analysis:** Shows call distribution between Female and Male.
*   **Interactive Filtering:** Uses slicers and filters to allow users to drill down into specific data segments.

## Data Sources

The dashboard uses sample call center data, including:

*   Call details (date, representative, city, duration, rating, etc.)
*   Revenue generated per call

## Usage

1.  Download the `Excel-Call centre performance project.xlsx` file .
2.  Open the file in Microsoft Excel.
3.  Use the slicer to explore the data and analyze different segments of the call center's performance.

## Dashboard Sections

*   **Summary Metrics:**  Provides a high-level overview of key performance indicators (KPIs).
*   **Monthly Call Volume:**  A chart showing call trends over the months.
*   **Daily Call Volume:**  A chart showing call trends over the days of the week.
*   **Representative Performance:**  A table ranking representatives by call count and revenue.
*   **City-Based Revenue:**  A table showing revenue generated from each city.
*   **Call Rating Distribution:** A table showing the distribution of call ratings.
*   **Gender Distribution:** A table showing call distribution between Female and Male.

## Representative Performance Analysis

The dashboard includes a detailed analysis of individual representative performance:

*   **Representative Ranking:** Ranks representatives based on call volume and total revenue.
*   **Individual Representative Summary:** Provides a summary of a selected representative's performance, including their percentage of total calls, call rank, and revenue rank.
